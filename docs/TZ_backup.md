# Tiyn «Глина»: бэкап и восстановление, ТЗ v1

Макеты Дизайнера: /workspace/tiyn/backup/ (SHEET_backup_v1.jpg, backup_settings/confirm/error_{dark,light}_v1.png, вставки _inset_*).
Размеры, цвета и тексты брать оттуда. Ниже логика и мои правки к макетам.

## 1. Экран «Настройки» (новый)
- Вход: иконку колокольчика в шапке главной заменить на шестерёнку (24 dp, тот же стиль). Она открывает «Настройки». Отдельную шторку напоминания убрать, напоминание переезжает сюда.
- Шапка: кнопка «Назад» и «Настройки» (Golos 22/700), как на экране «Копилки».
- Секция «Напоминание»: строка «Напоминать в ЧЧ:ММ» с переключателем. Тап по строке открывает выбор времени (текущая логика remind_on/remind_h/remind_m).
- Секция «Данные»: карточка 328 шириной, радиус 20, две строки по 56 dp и делитель.
  - «Сохранить копию» (иконка вниз), «Восстановить из копии» (иконка вверх). Иконки в кружках с акцентом 15%. Шевронов нет.
  - Под карточкой Golos 13: «Последняя копия: 14 нояб., 17:55». Если копий не было: «Копий ещё не было» и строка «Сохрани копию, чтобы не потерять записи».

## 2. Формат файла (правка к макету)
- Расширение **.json**, а не .tiyn. Файловые менеджеры Android и file_picker плохо фильтруют и открывают свои расширения, у файла без MIME-типа выбор может быть недоступен, а Telegram или Диск могут его переименовать. Признак «это копия Tiyn» хранить внутри файла.
- Имя: `tiyn_2026-11-14.json`. Если сохраняешь несколько раз за день, система сама добавит номер.
- Содержимое (UTF-8, с отступами):
```json
{
  "app": "tiyn",
  "version": 1,
  "createdAt": "2026-11-14T17:55:00+05:00",
  "data": {
    "transactions": [ ... ],
    "plans": [ ... ],
    "piggyStart": 8000,
    "lastCatExpense": "Еда",
    "lastCatIncome": "Стипендия",
    "remind": { "on": true, "h": 21, "m": 0 }
  }
}
```
  - transactions и plans кладём как массивы объектов, а не строку JSON внутри JSON. Поля те же, что сейчас в моделях.
  - Ключи prefs, которых нет в файле, при восстановлении сбрасываются к значениям по умолчанию.

## 3. Сохранение
- Тап «Сохранить копию»: собрать JSON и открыть системное окно «Сохранить как» (Storage Access Framework, `file_picker` `saveFile(bytes: ...)`). Разрешение на хранилище не запрашивать.
- Если файл сохранён: снекбар «Копия сохранена» и обновить «Последняя копия» (prefs `last_backup_at`).
- Если пользователь отменил окно: ничего не показывать и дату не менять.
- Ошибка записи: снекбар «Не удалось сохранить копию».

## 4. Восстановление
1. Тап «Восстановить из копии» открывает выбор файла (`file_picker`, type any; фильтр по json не включать, MIME у файлов из Telegram бывает любой).
2. Файл читается и проверяется **целиком, до каких-либо изменений**:
   - корректный JSON, `app == "tiyn"`, иначе ошибка «Это не копия Tiyn»;
   - `version` больше поддерживаемой: «Копия из новой версии Tiyn. Обнови приложение»;
   - у каждой транзакции есть id, целый amount, дата, которую можно разобрать, и kind; иначе «Файл повреждён».
   Любая ошибка показывает шторку ошибки по макету (у «!» r=28, «Файл не подходит», причина, «Твои данные не изменились»). Кнопки «Выбрать другой файл» и «Закрыть».
3. Шторка подтверждения по макету: имя файла и дата createdAt, превью «Записей / Баланс / Копилка». Баланс и Копилку считать той же функцией, что на главной, правила из TZ_days.md, раздел 8, не дублировать. Плашка «Текущие данные заменятся. Перед заменой мы сохраним их автоматически.» Кнопки «Заменить» (акцент, 52 dp) и «Отмена».
4. «Заменить»:
   - сначала сохранить текущее состояние в том же формате в prefs `restore_undo`. Храним одну, последнюю, автокопию;
   - записать все ключи; если запись упала, вернуть данные из `restore_undo`;
   - пересоздать или отменить напоминание по новым remind_*, обновить домашний виджет (HomeWidget), перерисовать главную;
   - закрыть настройки, вернуться на главную, показать снекбар «Данные восстановлены» с «Отменить» (около 6 с). «Отменить» возвращает данные из `restore_undo` тем же путём.
5. Снекбары 328×48, радиус 16, на 12 dp выше плавающей панели. Действие в тёмной теме #9E3A1E, как у Дизайнера.

## 5. Не делать
Шифрование, автобэкап по расписанию, облако, экспорт в CSV, слияние копий (только замена).

## 6. Проверка
- Тест: сохранить, затем восстановить, получаем тот же список транзакций, планы, piggyStart, remind.
- Тесты на ошибки: не JSON; JSON без app; version 99; транзакция без amount. Во всех случаях prefs не изменились.
- Тест «Отменить» после восстановления возвращает прежние данные.
- На телефоне: сохранить в «Загрузки», удалить пару записей, восстановить, проверить, что всё вернулось, виджет обновился и напоминание пришло в нужное время.
- Тёмная и светлая тема совпадают с макетами, текст «Последняя копия» обновляется.

# Дополнение v1.1: тема и акцент (в том же экране «Настройки»)

Порядок секций: «Оформление», «Напоминание», «Данные». Карточки как в «Данных» (328, радиус 20, строки 56).

## 7. Тема
- Строка «Тема», справа текущее значение («Как в системе», «Светлая» или «Тёмная»). Тап открывает маленькую шторку из трёх радио-строк по 56 dp. Отдельный экран не нужен.
- По умолчанию «Как в системе» (ThemeMode.system). Хранить в prefs `theme_mode`: system, light или dark.
- Применяется сразу, без перезапуска. При запуске тема читается до первого кадра, чтобы не мигала светлая тема.
- Сплэш и домашний виджет следуют выбранной теме: для виджета передавать через HomeWidget флаг dark и акцент.

## 8. Акцент
- Строка «Акцент», справа кружок 20 dp текущего цвета. Тап открывает шторку с тремя кружками по 48 dp и подписями под ними. У выбранного кружка обводка 2 dp ink и галочка.
- Варианты (light accent / light accentText / dark accent=accentText), контраст проверен, везде ≥4.5:

| id | Название | light accent | light accentText | dark accent |
|---|---|---|---|---|
| clay (по умолчанию) | Глина | #B84728 | #9E3A1E | #E39270 |
| red | Красный (классика Tiyn) | #D71921 | #B3151C | #F28C85 |
| blue | Синий | #2F5DA8 | #2A5396 | #8FB0E6 |

  onAccent не меняется: #FFF7F0 в светлой теме, #1A1613 в тёмной.
  Действие снекбара в тёмной теме: accentText из светлой палитры (сейчас #9E3A1E; у red будет #B3151C, у blue #2A5396).
- Меняются только accent, accentText и производные от них (заливка 15%, плашки, FAB, активная вкладка, точка в сплэше, акцент виджета). Цвета категорий, pos (доход) и ink не трогать.
- Хранить в prefs `accent`: clay, red или blue. Неизвестное значение превращается в clay.
- Иконку приложения не менять: она всегда терракотовая. Динамическую иконку не делать.

## 9. Бэкап
- Добавить в `data` поля `"themeMode"` и `"accent"`. При восстановлении применять их сразу. Если полей нет, оставлять текущие значения (старые копии остаются совместимы, version остаётся 1).

## 10. Не делать
Второй интерфейс в стиле старого Tiyn, свободный выбор цвета (color picker), AMOLED-тему.

## 11. Проверка
- Переключить все 3 темы и все 3 акцента: экран меняется сразу, после перезапуска выбор сохраняется, вспышки другой темы при старте нет.
- Виджет и сплэш берут тему и акцент.
- Скриншоты главной и шторки «+» во всех 6 сочетаниях темы и акцента показать Аблайхану.
