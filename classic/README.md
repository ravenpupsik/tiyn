# Tiyn (классика)

Android-приложение на Flutter для учёта личных денег: доходы, расходы, Копилка и планы. Всё работает офлайн, данные лежат на телефоне. Интерфейс на русском, светлая и тёмная тема, стиль в духе Nothing: серебристый фон, точечный шрифт Doto и одна красная точка.

> Это классический вид. Версия «Глина» лежит в отдельной папке и использует тот же `applicationId` (`com.moneycash.money_app`), поэтому при установке одна заменяет другую.

## Возможности

- **Главная**: карточка «На руках» с доходами и расходами за месяц, «Свободно» после планов, плашки «Копилка» и «Запланировано», лента операций по дням с итогом дня.
- **Кнопка «+»**: шторка расхода или дохода с категорией, заметкой и датой; правка по тапу, удаление свайпом с «Вернуть».
- **Копилка**: «Положить» и «Снять». Переводы не считаются ни доходом, ни расходом. Ни Копилка, ни «На руках» не уходят в минус.
- **Статистика**: кольцо расходов по категориям, «7 дней» со столбиками, «Месяц» или свой период, сравнение с прошлым месяцем.
- **Планы**: запланированные траты; «Свободно» = «На руках» минус планы; «Оплачено» превращает план в расход.
- **Напоминание** каждый вечер (14 дней вперёд); включается и настраивается в «Настройках».
- **Настройки** (шестерёнка на главной): тема (системная, светлая, тёмная), акцент (красный, синий, оранжевый), напоминание, копия данных в `.json` с восстановлением и «Отменить».
- **Виджет 4×2** «На руках»; «+» на нём открывает запись траты.
- Заставка при запуске.

## Структура проекта

```
lib/
  main.dart                    запуск: шейдер фона, напоминание, виджет, runApp
  app.dart                     TiynApp: MaterialApp, тема, язык, стартовый экран
  data/                        модели и хранение
    txn.dart                   операция (расход, доход, перевод в Копилку и обратно)
    plan.dart                  запланированная трата
    category.dart              категории расходов и доходов
    wallet.dart                все деньги: операции, планы, Копилка; чтение и запись в prefs
    period.dart                период статистики и правило «что считается тратой»
    backup_data.dart           формат копии `.json`, проверка файла, восстановление и «Отменить»
  services/                    работа с платформой
    reminder.dart              вечернее уведомление
    backup_io.dart             системные окна «Сохранить как» и «Выбрать файл»
    tiyn_home_widget.dart      картинка и данные для виджета на рабочем столе
  theme/
    tokens.dart                цвета, точечный шрифт Doto, длительность анимаций
    app_theme.dart             режим темы и акцент (`appTheme`), хранение в prefs
  utils/
    format.dart                форматирование сумм и дат
  widgets/                     общие виджеты: фон, стекло, карточки, кнопки, шторки, суммы, столбики
  screens/
    intro/                     заставка при запуске
    home/                      главная: страница, баланс, плашки Копилки и планов, нижняя панель, кнопка «+»
    editor/                    шит «+», перевод в Копилку, открытие редакторов и удаление с отменой
    piggy/                     экран Копилки и шторка «Сколько уже лежит?»
    stats/                     статистика, период, операции одной категории
    plans/                     планы, редактор плана
    settings/                  «Настройки»: оформление, напоминание, копия данных, шторки
test/                          тесты (fixtures/glina_backup.json: копия, записанная «Глиной»)
shaders/chrome.frag            шейдер «жидкого серебра» для фона
android/                       нативная часть: виджет (BalanceWidgetProvider), уведомления
assets/fonts/                  Doto (подключён), Tiny5 (лежит в папке, в pubspec не подключён)
```

Общие правила: экран лежит в `screens/<название>/`, всё, что нужно нескольким экранам, в `widgets/` или `utils/`. Логика денег (`data/`) не зависит от интерфейса.

## Где хранятся данные

Всё в `SharedPreferences` (на телефоне, без интернета):

| Ключ | Что внутри |
| --- | --- |
| `transactions` | JSON-список операций |
| `plans` | JSON-список планов |
| `piggy_start` | сколько уже лежало в Копилке к началу учёта |
| `remind_on`, `remind_h`, `remind_m` | напоминание: включено, час, минута |
| `theme_mode` | `system`, `light` или `dark` |
| `accent` | `red`, `blue` или `orange`; любое другое значение (например `clay` от «Глины») читается как `red` |
| `last_backup_at`, `restore_undo` | служебные: время последней копии и автокопия для «Отменить» |
| `last_cat_expense`, `last_cat_income` | пишет «Глина»; классика их не использует, но при копии и восстановлении сохраняет |

## Копия данных

«Настройки → Данные → Сохранить копию» пишет файл `tiyn_ГГГГ-ММ-ДД.json`: `{"app": "tiyn", "version": 1, "createdAt": ..., "data": {...}}`. Формат тот же, что у «Глины», файл открывается в обоих стилях в обе стороны. Новые поля необязательные, `version` остаётся 1. Неизвестные категории показываются как «Другое». Перед заменой текущие данные сохраняются автоматически, это даёт «Отменить». После восстановления перепланируется напоминание и перерисовывается виджет.

## Запуск и сборка

Нужен Flutter SDK (Dart `^3.13`). Один раз: `flutter pub get`.

```
flutter run                    # запуск на подключённом телефоне или эмуляторе
flutter build apk --release    # APK: build/app/outputs/flutter-apk/app-release.apk
```

Версия задаётся в `pubspec.yaml` (`version: 1.0.0+8`, у «Глины» на телефоне 7, так что классика ставится поверх с сохранением данных). Осторожно: тот же `applicationId`, что у «Глины». Установка этого APK поверх «Глины» заменит её; данные общие.
