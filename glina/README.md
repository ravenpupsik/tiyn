# Tiyn «Глина»

Android-приложение на Flutter для учёта личных денег: доходы, расходы, Копилка и планы. Всё работает офлайн, данные лежат на телефоне. Интерфейс на русском, светлая и тёмная тема, три акцента (Глина, Красный, Синий).

## Возможности

- **Главная**: карточка «На руках» со «Свободно» и расходами за неделю, лента операций по дням.
- **Быстрый ввод**: сумма и тап по категории сразу добавляют расход (4 секунды на «Отменить»).
- **Шит «+»**: расход или доход с категорией, заметкой и датой; правка и удаление свайпом.
- **Копилка**: перевод денег в Копилку и обратно. Переводы не считаются расходами. Баланс и Копилка не уходят в минус.
- **Статистика**: расходы по категориям (кольцо), «7 дней», «Месяц» или свой период.
- **Планы**: запланированные траты; «Свободно» = «На руках» минус планы; «Оплачено» превращает план в расход.
- **Напоминание** каждый вечер (14 дней вперёд, время настраивается).
- **Виджет 4×2** «На руках» на рабочем столе; «+» на нём открывает запись траты.
- **Настройки**: напоминание, оформление (тема и акцент), резервная копия и восстановление (JSON-файл).
- Заставка при запуске.

## Структура проекта

```
lib/

  app.dart                     TiynApp: MaterialApp, тема, язык, стартовый экран

    plan.dart                  запланированная трата
    category.dart              категории расходов и доходов
    wallet.dart                все деньги: операции, планы, Копилка; чтение и запись в prefs
    period.dart                период статистики и правило «что считается тратой»
    backup_data.dart           формат файла копии, проверка и запись при восстановлении
  services/                    работа с платформой
    reminder.dart              вечернее уведомление
    tiyn_home_widget.dart      картинка и данные для виджета на рабочем столе
    backup_io.dart             системные окна «Сохранить как» и «Выбрать файл»
  theme/                       оформление «Глина»
    tokens.dart                цвета, акценты, шрифты
    app_theme.dart             выбранные тема и акцент (хранятся в prefs)
    glina_theme.dart           ThemeData для светлой и тёмной темы
    cat_icons.dart             линейные значки категорий
  utils/                       форматирование сумм и дат, ввод цифр с пробелами
  widgets/                     общие виджеты: фон, карточки, кнопки, шиты, суммы, столбики
  screens/
    intro/                     заставка при запуске
    home/                      главная: страница, шапка, баланс, быстрый ввод, лента, нижняя панель
    editor/                    шит «+», перевод в Копилку, открытие редакторов и удаление с отменой
    piggy/                     экран Копилки
    stats/                     статистика, период, операции одной категории
    plans/                     планы, редактор плана
    settings/                  настройки, шторки темы и копии, снекбары
test/                          тесты и генерация картинок экранов (превью)

assets/fonts/                  шрифты Golos Text, Literata, Nunito (лицензии OFL рядом)
```

Общие правила: экран лежит в `screens/<название>/`, всё, что нужно нескольким экранам, в `widgets/` или `utils/`. Логика денег (`data/`) не зависит от интерфейса.

## Где хранятся данные

Всё в `SharedPreferences` (на телефоне, без интернета):

| Ключ | Что внутри |
| --- | --- |
| `transactions` | JSON-список операций |
| `plans` | JSON-список планов |
| `piggy_start` | сколько уже лежало в Копилке к началу учёта |
| `last_cat_expense`, `last_cat_income` | последняя выбранная категория (предвыбор в шите) |
| `remind_on`, `remind_h`, `remind_m` | напоминание: включено, час, минута |
| `theme_mode`, `accent` | тема (`system`, `light`, `dark`) и акцент (`clay`, `red`, `blue`) |
| `last_backup_at` | когда делалась последняя копия (служебный) |
| `restore_undo` | автокопия перед восстановлением для «Отменить» (служебный) |

## Резервная копия

Файл `tiyn_ГГГГ-ММ-ДД.json` (UTF-8, JSON с отступами):

```json
{
  "app": "tiyn",
  "version": 1,
  "createdAt": "2026-11-14T17:55:00+05:00",
  "data": {
    "transactions": [], "plans": [], "piggyStart": 0,
    "lastCatExpense": null, "lastCatIncome": null,
    "remind": { "on": false, "h": 21, "m": 0 },
    "themeMode": "system", "accent": "clay"
  }
}
```

Перед восстановлением файл проверяется целиком (`app == "tiyn"`, версия, поля). Данные заменяются только после подтверждения; текущее состояние сохраняется в `restore_undo`. Служебные ключи в файл не попадают.

## Запуск и сборка

Нужен Flutter SDK (Dart `^3.13`). Один раз: `flutter pub get`.

```
flutter run                    # запуск на подключённом телефоне или эмуляторе
flutter build apk --release    # APK: build/app/outputs/flutter-apk/app-release.apk
```

Версия задаётся в `pubspec.yaml` (`version: 1.0.0+7`). Для установки поверх прежней версии подпись должна совпадать (ключ тот же, на котором собирали раньше), номер после `+` должен расти:

```
adb install -r build/app/outputs/flutter-apk/app-release.apk
```
